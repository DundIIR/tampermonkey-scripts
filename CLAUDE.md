# Tampermonkey Scripts

Личная коллекция пользовательских скриптов (userscripts) для Tampermonkey. Пользователь пишет скрипты под свои рабочие нужды, заливает их в этот репозиторий на GitHub, а Tampermonkey подключает их по прямой ссылке на raw-файл (`@updateURL`/`@downloadURL`) — так скрипты автоматически обновляются в браузере при новом коммите в `main`.

Подробное описание скриптов см. в [README.md](README.md).

## Как со мной обычно работают

Пользователь обращается с двумя типами задач:
1. **Создать новый скрипт** — новый `*.user.js` файл в корне проекта.
2. **Отредактировать существующий скрипт** — указывает какой файл менять.

## Правила версионирования (обязательно)

Версия указывается в шапке файла в строке `// @version`.

- **При создании нового скрипта** — всегда ставь `// @version 1.0.0`.
- **При редактировании существующего скрипта** — версию нужно поднять **один раз за сессию**, не на каждое отдельное изменение. То есть: если это первое редактирование данного файла в текущей сессии — подними версию перед тем как вносить правки. Если в этой же сессии затем вносятся ещё правки в тот же файл — версию больше не трогай, она уже актуальна.
- Формат версии — семантический (`MAJOR.MINOR.PATCH`). Если пользователь не просил конкретный тип бампа, по умолчанию поднимай PATCH (например `1.0.5` → `1.0.6`). Если правки существенные — уточни, что за версия ожидается или подними MINOR/MAJOR по контексту.

## Правило выдачи ссылки

Когда пользователь просит "ссылку" (без уточнений) в контексте конкретного скрипта — отдавай ссылку на установку в Tampermonkey для этого скрипта, то есть значение `@updateURL`/`@downloadURL` из шапки файла (`https://raw.githubusercontent.com/DundIIR/tampermonkey-scripts/main/<file>.user.js`).

- Если в контексте сообщения/сессии прикреплён или упомянут конкретный файл — ссылку давай именно на него.
- Если непонятно, о каком скрипте речь — уточни у пользователя, прежде чем отдавать ссылку.

## Структура скрипта

Все скрипты — самостоятельные IIFE-файлы `*.user.js` со стандартной шапкой Tampermonkey:

```js
// ==UserScript==
// @name         ...
// @namespace    http://tampermonkey.net/
// @version      X.Y.Z
// @description  ...
// @author       DundIIR
// @match        https://...
// @grant        none
// @updateURL    https://raw.githubusercontent.com/DundIIR/tampermonkey-scripts/main/<file>.user.js
// @downloadURL  https://raw.githubusercontent.com/DundIIR/tampermonkey-scripts/main/<file>.user.js
// ==/UserScript==
```

Особенности кодовой базы:
- Ванильный JS, без сборщиков и зависимостей (`@grant none`).
- UI/тексты кнопок и логов — на русском.
- Динамический контент страниц (GitLab, Claude, ChatGPT) отслеживается через `MutationObserver`.
- Копирование в буфер — через `navigator.clipboard.writeText` (с fallback на `document.execCommand('copy')` в review-copier).
