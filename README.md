# Tampermonkey Scripts

Личная коллекция пользовательских скриптов (userscripts) для [Tampermonkey](https://www.tampermonkey.net/).

Скрипты пишутся под собственные рабочие нужды, заливаются в этот репозиторий на GitHub и подключаются в Tampermonkey по прямой ссылке на raw-файл (`@updateURL` / `@downloadURL`) — так они автоматически обновляются в браузере при новом коммите.

## Скрипты

### gitlab-mr-copier.user.js
**GitLab MR Files Copier** — работает на `gitlab.silaunion.ru`.
- Добавляет кнопку "Copy bpm-ui" на вкладке изменений MR (в списочном режиме просмотра), которая копирует в буфер обмена список изменённых файлов внутри `bpm-ui/` (с количеством добавленных/удалённых строк), исключая изображения и файлы локализации.
- Рядом с кнопкой копирования пути к файлу в диффе добавляет ещё одну кнопку — скопировать только имя файла (без пути).

### gitlab-mr-review-copier.user.js
**GitLab MR Review Copier** — работает на `gitlab.silaunion.ru`.
- Кнопка "Copy review" на странице MR: через API GitLab выгружает все замечания ревью (discussions) и копирует их в буфер в виде отформатированного текста (с указанием файла, строки, статуса resolved/unresolved) — удобно вставлять в Claude Code для исправления замечаний.
- У каждого отдельного треда обсуждения добавляет иконку-кнопку для копирования только этого одного треда.
- На дашборде также подменяет ссылку "Merge requests" так, чтобы она сразу вела на список MR текущего пользователя.

### jira-issue-copier.user.js
**Jira Issue Copier** — работает на `jira.silaunion.ru`.
- На доске (RapidBoard) при открытой детальной панели задачи добавляет иконку-кнопку рядом с `.ghx-controls`, которая копирует в буфер номер и название задачи (например, `UIKIT-28 Замена таблиц на uikit Table - Приемы класса`).

### message-hider.user.js
**Message Hider (Claude + ChatGPT)** — работает на `claude.ai` и `chatgpt.com`.
- Добавляет к каждому ответу ассистента кнопки "скрыть" (blur) и "удалить" (скрыть полностью) с возможностью восстановить обратно.
- Полезно для скриншотов/демонстраций чата без показа содержимого ответов.

## Установка

1. Установить расширение [Tampermonkey](https://www.tampermonkey.net/).
2. Открыть нужный `*.user.js` файл в этом репозитории в виде raw (`https://raw.githubusercontent.com/DundIIR/tampermonkey-scripts/main/<файл>`).
3. Tampermonkey предложит установить скрипт — подтвердить установку.
4. Дальнейшие обновления подтягиваются автоматически благодаря `@updateURL`/`@downloadURL` в заголовке скрипта.
